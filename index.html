PROJECT Vibrating Grape Filtration System
ORGCornell University — Class Project
TOOLSSolidWorks / McMaster-Carr / Motor-Driven Mechanisms
STATUSPROTOTYPE TESTED

A vibrating filtration tray that mounts inside a vineyard harvester gondola, separating spotted lanternfly contamination from grape juice during harvest. My contribution was the motor-driven vibration linkage — CAD-designed and built from McMaster-Carr components — that agitates the straining tray to prevent clogging and keep juice flowing. Built with Flynn Basehart, Kathryn Moskal, Emma Harshberger, and Gavin Sneyd.
